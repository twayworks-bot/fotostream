1. **Docker 컨테이너화 인프라 구성**:
   - `Dockerfile`, `.dockerignore`, `docker-compose.yml`, `gunicorn.conf.py`, `main.py` 생성.
   - 포트 5000, Persistent Volume `/app/storage`, 헬스체크 구문 충족.
2. **Persistent Volume 연동 PATH 환경변수 확장**:
   - `DB_PATH`, `STORAGE_DIR`, `UPLOAD_DIR`, `BGM_DIR`, `TRANSCODE_DIR` 환경변수 지원.
   - `DB_PATH` 지정 시 자동으로 SQLite URI 생성 및 상위 디렉토리 생성 보장.
3. **`DEFAULT_PREFIX` 표준화 및 헬스체크 엔드포인트 연동**:
   - `url_prefix` (`/fotostream`) 및 `clean_prefix` (`fotostream`) 정규화.
   - Docker 헬스체크 `http://localhost:5000{prefix}/api/status` 즉시 응답 라우트 구현.
4. **`README.md` 작성 및 최신화**:

## 2. 작업 세부 계획 (WBS)

### Step 1: 설정 및 코어 모듈 업데이트
- `app/core/config.py`:
  - `DB_PATH` 필드 추가 (Optional[str] = None).
  - `clean_prefix`, `url_prefix`, `effective_db_url` 프로퍼티 추가.
  - `abs_ffmpeg_path`, `abs_ffprobe_path`에 `shutil.which` 시스템 PATH 탐색 로직 추가.
- `app/core/database.py`:
  - `create_engine`에서 `settings.effective_db_url` 사용.
- `app/main.py`:
  - `settings.url_prefix` 기반으로 docs, redoc, openapi, static, routers 마운트.
  - `@app.get(f"{url_prefix}/api/status")` 및 `@app.get("/api/status")` 헬스체크 핸들러 등록.
- `app/routers/bgm.py`, `app/routers/videos.py`, `app/services/task_queue.py`:
  - `settings.url_prefix` 활용하여 안전한 URL 생성.
- `app/routers/ui.py` & `app/templates/dashboard.html`:
  - `prefix` 및 `url_prefix` 전달하여 정적 파일 및 JS fetch 경로 이중 슬래시 방지.

### Step 2: 루트 엔트리포인트 및 서버 설정 파일
- `main.py`:
  - ASGI 진입점 (`from app.main import app`).
- `gunicorn.conf.py`:
  - `worker_class = "uvicorn.workers.UvicornWorker"`, `workers = 2`, `bind = "0.0.0.0:5000"`, `loglevel = "debug"`.
- `requirements.txt`:
  - `gunicorn>=23.0.0` 추가.

### Step 3: Docker 관련 파일 제작
- `Dockerfile`:
  - Base: `python:3.11-slim`.
  - 패키지: `ffmpeg`, `curl`.
  - `VOLUME ["/app/storage"]`.
  - `EXPOSE 5000`.
  - `HEALTHCHECK` (요구사항 그대로 적용).
  - `CMD` (요청된 Gunicorn 옵션 1 적용 및 Uvicorn 옵션 2 주석 제공).
- `.dockerignore`:
  - 불필요한 캐시, 가상환경, 테스트 임시 파일 제외.
- `docker-compose.yml`:
  - 볼륨 마운트 (`./storage:/app/storage`), 포트 매핑 (`5000:5000`), 환경변수 프리셋.

### Step 4: 종합 문서 `README.md` 작성
- 프로젝트 목적, 전체 아키텍처, 기능 상세, 로컬 실행 방법, Docker 빌드 및 실행(볼륨 연동), API 및 헬스체크 안내.
