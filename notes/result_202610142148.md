### 2.2 Dockerfile 사양 검증
1. **Persistent Volume 연동**:
   - `VOLUME ["/app/storage"]` 지시어를 통해 DB 및 미디어 영구 보존.
   - `DB_PATH=/app/storage/fotostream.db` 설정을 통해 컨테이너 외부 호스트 볼륨에 SQLite 파일 보존.
2. **노출 포트**: `EXPOSE 5000` 설정 완료.
3. **`DEFAULT_PREFIX` 환경변수 연동**:
   - `DEFAULT_PREFIX=/fotostream` 설정.
   - 앱 내부에서 선행 슬래시 유무(`fotostream` vs `/fotostream`)와 무관하게 `url_prefix` 및 `clean_prefix`로 자동 정규화.
4. **컨테이너 헬스체크 정의**:
   - `HEALTHCHECK --interval=30s --timeout=10s --retries=3 --start-period=5s \ CMD python -c "import os, requests; prefix = os.getenv('DEFAULT_PREFIX', ''); requests.get(f'http://localhost:5000{prefix}/api/status')"`
   - `/{prefix}/api/status` 엔드포인트가 HTTP 200 `{"status": "healthy", ...}`를 즉시 반환하도록 구현 완료.
5. **시작 CMD**:
   - Option 1 (Gunicorn 운영 서버) 기본 활성화 및 `gunicorn.conf.py` 연동.
   - Option 2 (Uvicorn 경량 서버) 가이드 포함.
