## 2. 작업 세부 계획 (WBS)

### Step 1: `.env.example` 템플릿 파일 생성
- 실제 비밀번호, PIN, 내부 경로가 없는 안전한 기본값 템플릿 작성.

### Step 2: `.gitignore` 업데이트
- 8대 보안 카테고리 구성:
  1. Environments & Secrets (.env, .env.*, tokens, private keys)
  2. Persistent Storage & User Media (storage/, downloads/, *.db, media files)
  3. Python Bytecode & Virtual Environments (__pycache__, .venv, eggs)
  4. Unit Test & Coverage Caches (.pytest_cache, .coverage, htmlcov)
  5. Local Host Binaries (bin/, *.exe, *.dll)
  6. Temporary Files & Logs (*.log, logs/, tmp/, scratch/, *.swp)
  7. Shell & Command Histories (.bash_history, .python_history)
  8. OS & IDE Metadata (.vscode, .idea, .DS_Store, Thumbs.db)

### Step 3: `.dockerignore` 업데이트
- Docker 이미지 빌드 관점의 보안 및 최적화 규칙 구성:
  - Git 및 VCS (.git, .gitignore)
  - Docker 관련 매니페스트 (Dockerfile, docker-compose*.yml)
  - 환경변수 및 시크릿 (.env, secrets)
  - 호스트 바이너리 및 가상환경 (bin/, .venv/)
  - 내부 설계 문서 및 테스트 (notes/, tests/, *.md except README.md)
  - 런타임 스토리지 및 캐시 (storage/, downloads/, __pycache__)

### Step 4: 검증 및 문서 동기화
- `pytest` 실행하여 기존 기능 이상 유무 검증.
- `notes/requirement.md`, `notes/SPECIFICATION.md`, `notes/result_202610142222.md`, `notes/history.md` 업데이트.
