## 2. 요구사항 정밀 분석 (Requirement Analysis)

1. **블랙 영역 최소화 다중 토폴로지 면적 최적화 및 70% 노출 + 앰비언트 블러(Ambient Blur)**:
   - 고정 $N \times M$ 격자 조건에 얽매이지 않고, 주어진 사진들의 종횡비를 종합하여 캔버스 유효 채움 면적이 최대가 되는 토폴로지를 탐색.
   - 단일 종횡비 또는 혼합 사진에 대해 16:9 캔버스 상에서 세로 사진 배치 시 생기는 여백을 방지하기 위해 듀얼 레이어 렌더링 도입:
     - 배경 레이어: 이미지를 셀 영역에 맞춰 확대(Fill/Cover) 후 가우시안 블러(Gaussian Blur, radius=25) 적용하여 어색한 검정 여백(Pillarbox) 제거.
     - 전경 레이어: 원본 사진의 비율을 100% 보존하면서 셀 크기의 70%(`exp_ratio = 0.70`)로 중심에 선명하게 노출.
   - 줌인 애니메이션 시 원본 사진을 자르지 않고 전체 이미지를 보여주도록 카메라 경로 및 스케일 유지.

2. **기본 BGM 프리셋 자동 등록 비활성화 및 수동 관리 전환**:
   - `app/main.py` 기동 시 `seed_default_bgm()` 자동 호출 중단.
   - `bgm_manager.py`의 기본 프리셋 음원 자동 생성 로직 비활성화 및 기존 생성된 프리셋 음원/DB 레코드 정리 기능 제공.
   - 관리자가 향후 직접 고품질 BGM을 업로드 및 관리할 수 있도록 순수 수동 관리 체제로 전환.

3. **순수 9:16 및 올 세로형(All-Portrait) 9:16 영상 자동 합성 (Shorts / Reels 규격)**:
   - 업로드된 모든 이미지가 세로형($W < H$, 종횡비 $< 0.98$)인 경우, 비디오 해상도를 16:9 가로형이 아닌 9:16 세로형(예: 1080p 기준 $1080 \times 1920$, 720p 기준 $720 \times 1280$)으로 자동 전환.
   - 9:16 비율이 아닌 세로 사진(예: 3:4, 4:5 등)인 경우에도 9:16 세로 캔버스에 최적화하여 렌더링.
   - 세로형 영상 렌더링 시에는 이미지 잘림(Crop) 없이 **100% 전체 이미지 노출 (`exp_ratio = 1.0`)** 원칙을 적용하며, 미세한 종횡비 불일치 여백은 앰비언트 블러로 자연스럽게 커버.

4. **16:9 및 9:16 반응형 비디오 프리뷰(Preview Modal) UI 적응형 전환**:
   - 대시보드 비디오 재생 팝업(Preview Modal)이 16:9 가로 고정에서 벗어나 영상의 해상도 메타데이터(`is_vertical` 또는 해상도 폭/높이)를 판별하여 동적으로 모달 창 폭과 종횡비를 조정:
     - 세로형 영상: `max-w-sm`, `aspect-[9/16]` 적용 (모바일 숏폼 뷰어 형태).
     - 가로형 영상: `max-w-3xl`, `aspect-video` (16:9 와이드스크린 형태).
   - 비디오 라이브러리 목록 카드에도 `9:16 Shorts` 및 `16:9 Widescreen` 뱃지 표기.

5. **문서화 관리 규칙 수립**:
   - `notes/history.md`: 개발 요구사항과 요약 누적
   - `notes/req_YYYYMMDDHHmm.md`: 사용자 원본 요구사항 및 계획 기록
   - `notes/result_YYYYMMDDHHmm.md`: 산출물 생성 기록
   - `notes/requirement.md`: 모든 요구 사항 누적 기록

## 3. 개발 계획 수립 (Implementation Plan)

### Step 1: 그리드 계산기 및 레이아웃 최적화 (`app/services/grid_calculator.py`)
- 다중 토폴로지 후보군을 생성하고 각 후보에 대해 종횡비 면적 점수(`calculate_coverage_score`)를 평가하여 최적 토폴로지 반환.
- 올 포트레이트(All-Portrait) 감지 시 9:16 세로형 캔버스 규격 산출 지원.

### Step 2: 비디오 합성 엔진 개선 (`app/services/video_synthesizer.py`)
- `render_image_with_ambient_fill()` 함수 구현:
  - `exp_ratio` 파라미터 지원 (16:9 캔버스 세로 이미지: 0.70 노출 + 가우시안 블러 배경 / 9:16 올 세로 영상: 1.0 노출 무크롭 + 블러 배경).
- `SynthesisResult` 객체 반환으로 합성 비디오의 해상도(`width`, `height`, `is_vertical`)를 큐 및 DB에 정밀 전달.

### Step 3: 작업 큐 및 해상도 메타데이터 연동 (`app/services/task_queue.py`)
- `video_synthesizer`의 결과를 받아 `Video.resolution` 필드에 세로 해상도(예: `1080x1920`)를 정확히 기록.

### Step 4: 기본 BGM 자동 시딩 중단 (`app/main.py`, `app/services/bgm_manager.py`)
- 서버 기동 수명주기에서 `seed_default_bgm()` 호출 제거.
- `clean_default_presets()` 구현으로 기존 프리셋 정리 지원.

### Step 5: 웹 대시보드 9:16 프리뷰 반응형 UI (`app/templates/dashboard.html`, `app/static/js/app.js`)
- `applyModalAspect(isVertical)` 함수를 통해 세로형/가로형 모달 크기 및 종횡비 전환.
- 갤러리 카드에 9:16 Shorts 뱃지 표시.

### Step 6: 테스트 스위트 확장 및 전체 검증
- 순수 9:16 및 3:4/4:5 올 세로형 영상 합성 및 무손실 100% 줌 검증 테스트 작성.
- 전체 18개 테스트 통과 확인.
