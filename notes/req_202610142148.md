## 1. 사용자 원본 요구사항 (User Raw Request)

```text
docker container를 생성하기 위한 Dockerfile을 생성하려고 합니다.

database 파일에 대한 persistent volume을 연동하기 위한 PATH 환경값을 설정합니다.

노출 포트는 5000번으로 설정합니다.

docker 컨테이너의 DEFAULT_PREFIX 환경세팅 값이 있어서 앱의 기본 PREFIX값을 지정합니다.
웹앱의 prefix 값는 DEFAULT_PREFIX를 참조 하여 기본 base URL로 작동합니다. 

컨테이너 헬스체크 정의 (요청한 사양에 맞춘 Prefix 경로 연동)
HEALTHCHECK --interval=30s --timeout=10s --retries=3 --start-period=5s \
    CMD python -c "import os, requests; prefix = os.getenv('DEFAULT_PREFIX', ''); requests.get(f'http://localhost:5000{prefix}/api/status')"

시작 CMD 는 다음 2개 중 하나를 참조하여 생성합니다.
1) # Gunicorn 운영서버로 기동 (요청한 사양에 맞춘 최적화 워커 및 디버깅 로그 옵션)
CMD ["gunicorn", "--bind", "0.0.0.0:5000", "--workers", "2", "--log-level", "debug", "--access-logfile", "-", "--error-logfile", "-", "--capture-output", "main:app"]

2) # Run the FastAPI server using Uvicorn on port 5000
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "5000"]
```

## 2. 요구사항 분석 및 해석 (Requirement Analysis)

1. **Dockerfile 제작**:
   - 베이스 이미지: 경량화된 Linux Python 런타임(`python:3.11-slim`).
   - 시스템 의존성: 비디오 합성을 위한 `ffmpeg`, `ffprobe`, `curl` 패키지 설치.
   - 포트 노출: `EXPOSE 5000`.
   - 데이터 볼륨: SQLite DB 및 미디어 저장소를 보존하기 위한 `VOLUME ["/app/storage"]`.
   - 헬스체크: 사용자가 지정한 정확한 명령 구문과 일치하는 `HEALTHCHECK` 등록.
     ```dockerfile
     HEALTHCHECK --interval=30s --timeout=10s --retries=3 --start-period=5s \
         CMD python -c "import os, requests; prefix = os.getenv('DEFAULT_PREFIX', ''); requests.get(f'http://localhost:5000{prefix}/api/status')"
     ```
   - 시작 CMD: 요청된 2가지 옵션 중 Gunicorn 운영서버 모드(Option 1)를 기본 활성화하고, Uvicorn 개발/경량 모드(Option 2)를 주석 및 가이드로 제공.
     - FastAPI ASGI 특성상 Gunicorn 구동 시 UvicornWorker 바인딩이 누락되면 sync worker 에러가 발생하므로, `gunicorn.conf.py`를 함께 구성하여 `worker_class = "uvicorn.workers.UvicornWorker"` 자동 연동.

2. **Persistent Volume 연동을 위한 PATH 환경값 설정**:
   - `DB_PATH`: 데이터베이스 파일의 영구 저장 경로(예: `/app/storage/fotostream.db`).
   - `STORAGE_DIR`: 스토리지 루트 디렉토리(`/app/storage`).
   - `UPLOAD_DIR`: 업로드 파일 보존 디렉토리(`/app/storage/uploads`).
   - `TRANSCODE_DIR`: 변환된 영상 보존 디렉토리(`/app/storage/transcoded`).
   - `BGM_DIR`: BGM 음원 파일 디렉토리(`/app/storage/bgm`).
   - `DB_PATH` 환경변수를 통해 사용자가 마운트한 볼륨 경로의 DB 파일과 직접 연동되도록 `effective_db_url` 로직 추가.

3. **URL Base 경로 `DEFAULT_PREFIX` 표준화 및 연동**:
   - 컨테이너 환경변수 `DEFAULT_PREFIX` (기본값: `/fotostream` 또는 `fotostream`).
   - 선행 슬래시 유무와 관계없이 안전하게 정규화(`url_prefix`: `/fotostream`, `clean_prefix`: `fotostream`).
   - 헬스체크 엔드포인트 지원: `http://localhost:5000{prefix}/api/status` 및 `http://localhost:5000/api/status` 모두 200 OK를 반환하는 전용 경량 헬스체크 라우트 신설.

4. **루트 엔트리포인트 `main.py` 신설**:
   - 사용자가 제공한 두 가지 CMD 구문 모두 `main:app`을 지정하므로, 프로젝트 루트에 `main.py`를 생성하여 `app.main`의 `app` 객체를 노출.

5. **`README.md` 작성 및 유지관리**:
   - 프로젝트 목적 및 핵심 기능 설명 (NxM 매트릭스, 하이브리드 고해상도 줌, 1080p 표준, 밝은 BGM).
   - 로컬 개발 환경 실행 방법 (`uv`, `venv`, `python main.py`).
   - Docker 배포 방법: Dockerfile 빌드, 단일 컨테이너 실행, 볼륨 마운트, `docker-compose.yml` 가이드.
   - 환경변수 레퍼런스 표 (`DEFAULT_PREFIX`, `DB_PATH`, `STORAGE_DIR`, `PORT` 등).
   - API 엔드포인트 명세 및 헬스체크 가이드.
