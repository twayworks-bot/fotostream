## 1. 개선 및 구현 내역

### 1.1 하이브리드 해상도 줌인/줌아웃 트랜지션 (Hybrid Resolution Zoom)
- **문제 해결**:
  - 기존 방식: 전체 캔버스 상의 작은 셀 썸네일(약 200~300px)을 단순 디지털 크롭 확대하여 줌인 완료 시 화질이 뭉개지고 흐려지는 현상 발생.
  - 개선 방식: **듀얼 레이어 프리렌더링 및 동적 알파 크로스페이드(Seamless Crossfade)** 도입.
- **파이프라인 세부 동작**:
  1. **듀얼 레이어 생성**:
     - Layer A: 전체 캔버스($W \times H$) 상에 각 이미지를 셀 크기로 배치한 베이스 매트릭스 캔버스.
     - Layer B: 각 원본 이미지를 출력 해상도($W \times H$)에 맞게 LANCZOS 알고리즘으로 사전 피팅한 100% 원본 고해상도 이미지.
  2. **동적 줌인 구간 ($0.35 \le t \le 0.70$)**:
     - 매트릭스 뷰에서 대상 셀 중심점으로 부드럽게 줌을 시작한 뒤, 중간 구간에서 Layer A(크롭 뷰)와 Layer B(고해상도 원본)를 코사인 가중치로 알파 블렌딩하여 이질감 없이 스위칭.
     - $t > 0.70$ 시점에 **100% 고해상도 원본 프레임에 도달**.
  3. **고해상도 원본 집중 감상 (Hold 1.5초)**:
     - 45프레임 동안 **100% 고해상도 원본 이미지 프레임을 직접 송출**하여 원본 사진의 선명한 디테일과 텍스처를 온전히 제공.
  4. **동적 줌아웃 구간 ($0.30 \le t \le 0.65$)**:
     - 고해상도 뷰에서 줌아웃을 개시한 뒤 중간 지점에서 Layer A 매트릭스 뷰로 매끄럽게 크로스페이드 복귀.
