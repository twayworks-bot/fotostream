## 1. 최소 기능 제품 (MVP: Minimum Viable Product) 정의 (BGM 라이브러리 확장 반영)

FOTOSTREAM 프로젝트의 핵심 가치와 새롭게 추가된 BGM 라이브러리 관리 기능을 통합한 MVP 범위를 다음과 같이 정의합니다.

### 1.1 MVP 핵심 포함 범위
1. **환경 및 기본 설정**:
   - `.env` 연동 및 경로/포트(`5000`)/프리픽스(`/fotostream`) 로드
   - `FFMPEG_PATH`, `FFPROBE_PATH` 유효성 검사 및 안내
   - BGM 음원 보관 디렉토리(`storage/bgm/`) 및 업로드/트랜스코딩 디렉토리 자동 생성
2. **무료 BGM 라이브러리 및 오디오 미리듣기**:
   - 관리자 BGM 음원 등록 API 및 UI (Pixabay Music 등 무료 음원 파일, 제목, 장르, 라이선스)
   - BGM 목록 조회 및 실시간 브라우저 오디오 스트리밍 미리듣기
   - 시스템 최초 구동 시 3~4개의 저작권 무료 번들 프리셋 BGM 자동 시딩
3. **NxM 그리드 계산 및 비디오 합성 엔진**:
   - $1 \le K \le 49$개 사진에 대한 $M=N$ 또는 $N = M \pm 1$ 최적 그리드 산출
   - 720p 해상도 기반 매트릭스 전체 뷰 $\rightarrow$ 개별 사진 줌인 $\rightarrow$ 줌아웃 복귀 $\rightarrow$ 순차 슬라이딩 렌더링
   - 선택된 BGM 음원과 비디오 합성 (자동 루프 및 부드러운 페이드아웃)
   - 최대 비디오 파일 크기 $\le 100\text{MB}$, 최대 재생 시간 $\le 10\text{분}$ 검증
4. **비동기 큐 및 동시성 제어**:
   - 동시 비디오 합성 작업 수 **최대 3개** 제한 (`asyncio.Semaphore(3)`)
   - 작업 상태 라이프사이클 관리 (`QUEUED`, `PROCESSING`, `COMPLETED`, `FAILED`)
5. **스트리밍 엔드포인트 및 동시 세션 제어**:
   - 최종 동영상 전용 스트리밍 URL (`/fotostream/api/v1/videos/{video_id}/stream`)
   - HTTP Range Request (206 Partial Content) 지원
   - 동시 스트리밍 세션 수 **최대 10개** 제한 (`ActiveStreamRegistry`)
6. **웹 대시보드 (Demo Admin UI)**:
   - `/fotostream` 경로 접근
   - 사진 다중 업로드(최대 49장) 드래그 앤 드롭
   - **BGM 선택 카드 및 관리자 BGM 등록 모달** (미리듣기 재생, 무드 태그, 선택 상태 표시)
   - 실시간 작업 큐 상태 모니터링 (대기 및 진행률 프로그레스 바)
   - 생성된 비디오 라이브러리 목록 확인 및 웹 플레이어 즉시 스트리밍 재생

## 2. 단계별 세부 개발 추진 계획 (Milestones)

### Phase 1: 기반 인프라, 설정 및 BGM 스토리지 구축 (Step 1)
- `requirements.txt` 작성 (`fastapi`, `uvicorn`, `pydantic-settings`, `pillow`, `sqlalchemy`, `aiofiles`, `jinja2`, `python-multipart` 등)
- `core/config.py`: `.env` 매핑 및 BGM 디렉토리 경로 추가
- `core/database.py` 및 SQLite 초기화 (`models/job.py`, `models/video.py`, `models/bgm.py`)
- 디렉토리 자동 생성 (`storage/uploads`, `storage/bgm`, `storage/transcoded`, `storage/hls`)

### Phase 2: BGM 라이브러리 엔진 및 시드 음원 적재 (Step 2)
- `services/bgm_manager.py`:
  - BGM 등록, 음원 메타데이터 파싱(재생시간, 파일크기)
  - 초기 번들 프리셋 음원 자동 시딩 로직 구현
- `routers/bgm.py`:
  - `GET /fotostream/api/v1/bgm` (목록)
  - `POST /fotostream/api/v1/bgm` (관리자 등록)
  - `GET /fotostream/api/v1/bgm/{bgm_id}/stream` (오디오 미리듣기)

### Phase 3: 핵심 비디오 합성 엔진 및 BGM 오디오 믹서 (Step 3)
- `services/grid_calculator.py`: 최적 $N \times M$ 그리드 및 셀 좌표 계산기
- `services/audio_mixer.py`: BGM 오디오 루프 및 페이드아웃 필터그래프 빌더
- `services/video_synthesizer.py`: 720p 캔버스, 줌인/줌아웃 프레임 렌더링, FFmpeg 인코딩 파이프라인

### Phase 4: 비동기 작업 큐 및 동시성 제어기 (Step 4)
- `services/task_queue.py`:
  - `asyncio.Semaphore(3)` 기반 최대 3개 동시 워커 풀
  - 작업 상태 및 진행률 실시간 트래킹

### Phase 5: 비디오 스트리밍 매니저 및 비디오 API (Step 5)
- `services/stream_manager.py`: 동시 스트리밍 최대 10개 슬롯 제어
- `routers/videos.py`: HTTP Range Request 206 스트리밍, 다운로드, 삭제 API

### Phase 6: 작업 관리 API 및 시스템 모니터링 (Step 6)
- `routers/jobs.py`: `POST /fotostream/api/v1/jobs` (사진 1~49장 + BGM ID 연계)
- `routers/system.py`: `GET /fotostream/api/v1/system/status`

### Phase 7: 웹 대시보드 UI 구현 (Step 7)
- `templates/dashboard.html` 및 `templates/components/bgm_modal.html`
- `static/js/bgm_selector.js`: BGM 리스트 로드, 미리듣기(Play/Stop), 관리자 BGM 업로드 모달
- `static/js/app.js`: 사진 드래그앤드롭(49장 제한), 작업 큐 실시간 폴링, 비디오 플레이어

### Phase 8: E2E 통합 테스트 및 제약사항 검증 (Step 8)
- Pixabay BGM 선택 후 49장 사진 동영상 합성 시나리오
- 합성 영상 규격 검증 (720p, $\le 100\text{MB}$, $\le 10\text{분}$)
- 동시 합성 3개, 동시 스트리밍 10개 제약사항 검증
