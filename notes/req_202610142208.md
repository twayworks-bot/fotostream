## 1. 사용자 원본 요구사항 (User Raw Request)

```text
등록된 무료 BGM 라이브러리 리스트 중 항목을 삭제할 수 있도록 각 항목에 삭제버튼을 추가해주세요.
```

---

## 2. 요구사항 분석 및 개발 범위 (Requirement Analysis)

1. **기능 목적**:
   - 웹 대시보드의 무료 BGM 라이브러리 카드 목록에서 원치 않는 음원(잘못 업로드된 파일, 불필요한 트랙 등)을 사용자가 직접 삭제할 수 있도록 각 BGM 카드 항목에 직관적인 삭제(Delete) 버튼을 추가.

2. **UI/UX 요구사항**:
   - `app/static/js/bgm_selector.js`의 `renderBgmCards` 함수에서 각 BGM 카드의 우측(선택 라디오 버튼 좌측)에 삭제 버튼 배치.
   - 휴지통 아이콘(SVG) 또는 삭제 심볼을 적용하고, 마우스 호버 시 붉은색 계열(`hover:text-rose-400`, `hover:bg-rose-500/10`) 강조 효과 부여.
   - 클릭 시 이벤트 버블링 방지(`event.stopPropagation()`)를 적용하여 삭제 버튼 클릭 시 카드가 선택되지 않도록 처리.
   - 오작동 방지를 위해 브라우저 확인 팝업(`confirm`)을 띄워 사용자에게 삭제 의사를 확인.

3. **프론트엔드 - 백엔드 연동 로직**:
   - `DELETE /{prefix}/api/v1/bgm/{trackId}` API 호출.
   - 현재 오디오 미리듣기(Preview)로 재생 중인 트랙이 삭제되는 경우, 즉시 오디오 재생을 중지(`currentAudio.pause()`)하고 재생 아이콘 상태 초기화.
   - 현재 영상 합성을 위해 선택되어 있던 트랙이 삭제되는 경우 `selectedBgmId`를 초기화.
   - 삭제 완료 후 BGM 목록(`loadBgmTracks`)을 비동기로 재로드하여 UI에 즉시 반영.

4. **백엔드 및 데이터 무결성 검토**:
   - `app/routers/bgm.py`의 `DELETE /api/v1/bgm/{bgm_id}` 엔드포인트와 `BGMManager.delete_track()` 함수 검증.
   - DB 레코드 삭제 및 `storage/bgm/` 디렉터리 내 물리 오디오 파일 자동 정리(`unlink()`) 보장.
   - 기본 프리셋 삭제 시 재시작 시점의 동작 규칙(이미 초기화된 경우 삭제 상태 보존) 정립.
