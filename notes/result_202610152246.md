## 1. 개요 및 구현 산출물 목록

사용자의 요청에 따라 다음 5가지 핵심 기능이 성공적으로 개발 및 검증되었습니다:
1. **블랙 영역 최소화 면적 최적화**: 고정 $N \times M$ 격자 제한을 탈피하고, 다중 토폴로지 후보군 중 면적 채움 점수를 극대화하는 레이아웃 알고리즘 구현.
2. **70% 노출 + 앰비언트 블러(Ambient Blur)**: 16:9 와이드 화면에 세로형(9:16 등) 이미지를 배치할 때, 배경에 가우시안 블러(radius=25) 확대 레이어를 깔고 중심에 70% 원본 비율로 전경 이미지를 선명하게 노출하여 블랙 여백 해소.
3. **기본 BGM 자동 등록 비활성화**: 시스템 구동 시 기본 BGM 5곡 자동 시딩을 끄고 관리자 수동 등록 방식으로 전환.
4. **올 포트레이트(All-Portrait) 9:16 비디오 자동 제작**: 업로드된 모든 이미지가 세로형(9:16, 3:4, 4:5 등)인 경우 영상을 9:16 세로형(Shorts 규격, 예: 1080x1920)으로 자동 전환하고, 크롭 없는 100% 줌인(`exp_ratio = 1.0`) 애니메이션 적용.
5. **적응형 프리뷰 모달(Adaptive Preview Modal)**: 비디오 해상도에 맞춰 16:9 와이드(`max-w-3xl`)와 9:16 세로 숏폼(`max-w-sm`, `aspect-[9/16]`) 모달 뷰어로 동적 전환.

## 2. 주요 기능 구현 상세

### 2.1 다중 토폴로지 면적 최적화 및 70% 노출 + 앰비언트 블러
- **알고리즘**: 이미지 개수 $K$에 대해 가능한 모든 행/열 조합($N \times M \ge K$)을 탐색하고, 각 셀에 배치될 이미지들의 축척비와 여백을 계산하여 면적 채움 점수($\text{Score} = \sum \text{ImageArea} / \text{CanvasArea}$)가 가장 높은 최적 토폴로지를 자동 결정.
- **듀얼 레이어 렌더링 (`render_image_with_ambient_fill`)**:
  - 배경: 원본 이미지를 셀 전체 크기에 맞추어 확대(Cover)한 뒤 PIL `ImageFilter.GaussianBlur(radius=25)`를 적용하여 은은하고 세련된 배경 생성.
  - 전경: 원본 종횡비를 100% 보존하며 셀 크기의 70%(`exp_ratio = 0.70`)로 축소 배치하여 과도한 블랙 바 대신 부드러운 블러 배경이 채워지도록 연출.

### 2.2 기본 BGM 자동 시딩 제거
- `main.py` 기동 시 무조건 5곡의 프리셋을 생성하던 `seed_default_bgm()` 호출 제거.
- 필요 시 호출 가능한 `clean_default_presets()` 함수를 통해 DB와 파일 시스템에서 디폴트 프리셋 5곡을 안전하게 소거.
- 웹 UI는 BGM 목록이 비어 있을 경우 "등록된 배경음악이 없습니다. 관리자가 음원을 등록할 수 있습니다"라는 안내를 표시.

### 2.3 올 포트레이트(All-Portrait) 9:16 비디오 자동 제작
- 업로드된 이미지들의 너비/높이를 분석하여 모든 사진이 세로형($W < H$, 종횡비 $< 0.98$)인 경우, 비디오 해상도를 9:16(예: 1080p 설정 시 $1080 \times 1920$)으로 자동 설정.
- 순수 9:16이 아닌 3:4, 4:5 등의 세로 사진도 9:16 세로 캔버스에 최적화하여 배치.
- 세로 영상 합성 시에는 이미지를 크롭하지 않고 **100% 전체 영역을 줌인(`exp_ratio = 1.0`)**하여 사진의 온전한 디테일을 감상할 수 있도록 처리.

### 2.4 적응형 프리뷰 모달(Adaptive Preview Modal)
- 사용자가 완성된 비디오의 미리보기를 클릭할 때, 비디오의 해상도 문자열(예: `1080x1920` vs `1920x1080`)을 분석:
  - 세로형 영상: 모달 카드 폭을 `max-w-sm`으로 줄이고 비디오 래퍼를 `aspect-[9/16]` 클래스로 전환.
  - 가로형 영상: 모달 카드 폭을 `max-w-3xl`로 유지하고 `aspect-video` 클래스로 전환.
- 비디오 라이브러리 목록 카드에도 분홍색 `9:16 Shorts` 또는 인디고색 `16:9 Widescreen` 뱃지를 부착하여 사용자가 직관적으로 구분 가능.
